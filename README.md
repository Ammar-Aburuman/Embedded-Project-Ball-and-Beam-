# Ball and Beam Control System

A model-based Ball and Beam control project using **Dragon12-JR (HCS12)** for sensor data acquisition and **Arduino Uno + Simulink** for real-time PID control.

## Overview
- Ultrasonic sensors measure ball and target positions  
- Dragon12-JR handles timing and serial data packaging  
- Arduino Uno runs a Simulink-generated PID controller  
- Continuous rotation servo tilts the beam to stabilize the ball

## Tools & Hardware
- Dragon12-JR (HCS12)
- Arduino Uno
- MATLAB / Simulink
- HC-SR04 Ultrasonic Sensors
- Continuous Rotation Servo
